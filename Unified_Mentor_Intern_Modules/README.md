# Unified Mentor — Internship Modules

A collection of practical assignments completed during the Unified Mentor internship.

## Module 1: Vectors Using NumPy

This module introduces numerical computing with Python's NumPy library.

### Learning objectives

- Import NumPy and create arrays.
- Understand vectors, dimensions, and array shapes.
- Perform vector addition and subtraction.
- Apply scalar and element-wise multiplication.
- Calculate dot products.
- Understand transpose and basic matrix operations.
- Use NumPy universal functions for numerical calculations.

### Run the notebook

1. Install Python 3.
2. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

3. Start Jupyter:

   ```bash
   jupyter notebook
   ```

4. Open `Module_1_worksheet_completed.ipynb` and run the cells from top to bottom.

You can also upload the notebook to [Google Colab](https://colab.research.google.com/) and run it in your browser.

### Requirements

- Python 3.9+
- NumPy
- Jupyter Notebook
